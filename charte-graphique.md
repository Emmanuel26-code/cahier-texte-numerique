# Charte graphique

## Framework CSS
Bootstrap 5.3 (choisi pour sa simplicité et son responsive intégré).

## Couleurs
- Couleur principale : #1F4E79 (bleu)
- Couleur secondaire : #2E8B57 (vert)
- Fond de page : #F5F7FA
- Texte : #222222
- Erreurs : #B00020

## Police
Segoe UI, sans-serif

## Langue
Toute l'interface est en français.

## Responsive
Le site s'adapte au téléphone, à la tablette et à l'ordinateur.
